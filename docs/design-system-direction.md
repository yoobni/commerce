# 브랜드 톤 및 디자인 시스템 방향 정의

> 작성: Iseria (planner)
> 최종 수정: 2026-04-13
> 상태: 확정 대기 — Vivian(디자이너) 검토 및 사용자 승인 후 적용

---

## 1. 목표

대형견 의류 커머스의 **브랜드 정체성**을 시각 언어로 정의한다.
"반려동물 쇼핑몰"이 아니라 **"대형견 보호자를 위한 프리미엄 편집몰"**로 인식되어야 한다.
디자이너(Vivian)와 프론트엔드(Yuna)가 바로 작업 가능한 수준으로 원칙을 확정한다.

---

## 2. 포함 범위

- 브랜드 톤 키워드 및 성격 정의
- 색상 체계 방향
- 타이포그래피 원칙
- 간격/레이아웃 원칙
- 컴포넌트 설계 원칙
- 상태 패턴 (로딩, 스켈레톤, 빈 상태, 에러)
- 다국어 텍스트 길이 대응 규칙
- 모바일 우선 구조 기준
- 이미지 운용 원칙

## 3. 제외 범위

- 구체적 HEX 코드, 폰트 파일 선정 (Vivian 영역)
- 컴포넌트 라이브러리 코드 구현 (Yuna 영역)
- 어드민 디자인 시스템 (별도 문서로 분리)
- 아이콘/일러스트레이션 세부 가이드

---

## 4. 브랜드 톤 정의

### 4-1. 핵심 키워드 (Brand Personality)

| 키워드 | 의미 | 시각적 표현 |
|--------|------|-------------|
| **Clean** | 군더더기 없는 깔끔함 | 최소한의 장식, 명확한 위계, 정돈된 그리드 |
| **Premium** | 고급스러움, 신뢰 | 절제된 색상, 넉넉한 여백, 높은 이미지 품질 |
| **Calm** | 차분하고 편안한 | 저채도 팔레트, 부드러운 전환, 과한 모션 배제 |
| **Spacious** | 여유로운 공간감 | 넓은 마진, 충분한 패딩, 밀도 낮은 레이아웃 |

### 4-2. 보조 키워드

| 키워드 | 설명 |
|--------|------|
| **Trustworthy** | 정보가 정확하고 구조가 예측 가능 |
| **Warm but Restrained** | 따뜻하지만 과하지 않음. 귀여움이 아닌 존중의 따뜻함 |
| **Editorial** | 잡지처럼 이미지와 텍스트의 조화. 나열이 아닌 편집 |
| **Modern Commerce** | 최신 커머스 UX 관행을 따르되 트렌디함을 목적으로 하지 않음 |

### 4-3. 안티패턴 (하지 말아야 할 것)

| 금지 | 이유 |
|------|------|
| 귀엽고 동글동글한 톤 | 반려동물 = 귀여움이라는 클리셰. 대형견 보호자가 공감하지 않음 |
| 과한 애니메이션/파티클 | 체감 속도 저하 + 프리미엄 감도와 충돌 |
| 화려한 그라디언트/네온 | 고급 감도와 반대 |
| 빽빽한 정보 밀도 | Spacious 원칙 위반 |
| 지나치게 서구형 미니멀 | 서비스 감도가 없어짐. 한국적 절제감 유지 |
| 스톡 이미지 느낌 | 브랜드 신뢰 하락. 대형견이 주인공인 리얼 비주얼 필수 |

### 4-4. 브랜드 포지셔닝 비유

> **"무인양품(MUJI)의 절제 + Aesop의 소재감 + Mr Porter의 편집력"**을 대형견 세계에 적용한 것

- MUJI → 불필요한 것을 뺀 정돈된 구조
- Aesop → 소재와 텍스처가 주는 고급감
- Mr Porter → 이미지와 정보의 편집적 배치

## 5. 색상 체계 방향

### 5-1. 원칙

| 원칙 | 설명 |
|------|------|
| 저채도 중심 | 채도가 높은 색은 극히 제한적 사용 (CTA 버튼, 에러 등) |
| 뉴트럴 베이스 | 배경과 텍스트는 뉴트럴 톤 (off-white, warm gray, charcoal) |
| 따뜻한 뉴트럴 | 순수한 white(#FFFFFF)보다 약간 따뜻한 off-white 지향 |
| 컬러 최소화 | 브랜드 메인 컬러 1개 + 보조 1개 + 시스템 컬러(에러/성공/경고) |
| 이미지가 컬러 | 제품/대형견 이미지가 페이지의 색감을 담당 |

### 5-2. 색상 역할 구조

| 역할 | 방향 | 용도 |
|------|------|------|
| **Background** | Off-white ~ Warm white | 전체 배경 |
| **Surface** | White ~ Light warm gray | 카드, 모달, 입력 필드 |
| **Text Primary** | Charcoal (순수 검정 아님) | 제목, 본문 |
| **Text Secondary** | Warm gray | 보조 텍스트, 캡션 |
| **Brand Primary** | 저채도 자연색 계열 (Vivian 확정) | 로고, 주요 CTA, 강조 |
| **Brand Secondary** | Brand Primary의 보조색 | hover, 보조 UI |
| **CTA** | Brand Primary 또는 Charcoal | 구매 버튼, 핵심 액션 |
| **Error** | 저채도 레드 | 에러 메시지, 유효성 검사 실패 |
| **Success** | 저채도 그린 | 완료, 성공 상태 |
| **Warning** | 저채도 앰버 | 경고, 주의 |

### 5-3. 다크모드

- MVP에서 **다크모드 미지원** (범위 제외)
- 단, 색상 토큰을 CSS 변수/디자인 토큰으로 관리하여 추후 확장 가능하게 구조만 준비

## 6. 타이포그래피 원칙

### 6-1. 원칙

| 원칙 | 설명 |
|------|------|
| 가독성 우선 | 디스플레이 서체보다 본문 가독성이 높은 서체 |
| 언어별 서체 분리 | 라틴(en/de), 한글(ko), 일본어(ja) 각각 최적 서체 지정 |
| 위계 명확 | H1 ~ Body ~ Caption까지 크기·굵기 차이가 확실해야 함 |
| 자간/행간 여유 | Spacious 원칙에 맞게 행간(line-height) 넉넉하게 |
| 서체 수 최소화 | 본문 1개 + 제목용 1개 (또는 동일 서체 패밀리 내 weight 차이) |

### 6-2. 타이포 스케일 기준

| 레벨 | 용도 | 모바일 기준 | 데스크탑 기준 | 굵기 |
|------|------|------------|-------------|------|
| Display | 히어로 배너 | 28–32px | 40–48px | Bold/Semi-Bold |
| H1 | 페이지 제목 | 24–28px | 32–36px | Semi-Bold |
| H2 | 섹션 제목 | 20–22px | 24–28px | Semi-Bold |
| H3 | 카드 제목, 서브섹션 | 18–20px | 20–22px | Medium |
| Body Large | 상품 설명, 주요 본문 | 16px | 16–18px | Regular |
| Body | 일반 본문 | 14–15px | 15–16px | Regular |
| Caption | 보조 텍스트 | 12–13px | 13–14px | Regular |
| Overline | 라벨, 태그 | 11–12px | 12–13px | Medium/Semi-Bold |

### 6-3. 다국어 타이포 고려

| 언어 | 특성 | 대응 |
|------|------|------|
| **ko** (한국어) | 글자 폭 균일, 행간 넉넉해야 읽기 편함 | line-height 1.6~1.8 |
| **en** (영어) | 글자 폭 변동, 대소문자 높이차 | line-height 1.5~1.6 |
| **ja** (일본어) | 한자 포함 시 높이 큼, 세로쓰기 불필요 | line-height 1.7~1.8, 한자 혼합 가독성 확인 |
| **de** (독일어) | 단어가 매우 길음 (합성어), 대문자 명사 | 줄바꿈 규칙 필수, overflow 대비 |

## 7. 간격 및 레이아웃 원칙

### 7-1. 간격 체계

| 원칙 | 설명 |
|------|------|
| 8px 그리드 기반 | 모든 간격은 4px 또는 8px의 배수 (4, 8, 12, 16, 24, 32, 48, 64, 80, 96) |
| 컴포넌트 내부 패딩 넉넉하게 | Spacious 원칙. 버튼/카드/입력 필드 내부 패딩 충분히 |
| 섹션 간 간격 크게 | 섹션 구분은 선이 아닌 여백으로 |
| 터치 타겟 최소 44px | 모바일 터치 영역 보장 |

### 7-2. 레이아웃 그리드

| 항목 | 모바일 (< 768px) | 태블릿 (768–1024px) | 데스크탑 (> 1024px) |
|------|------------------|---------------------|---------------------|
| 컬럼 | 4 | 8 | 12 |
| 거터 | 16px | 24px | 24–32px |
| 마진 | 16–20px | 32px | auto (max-width 제한) |
| 최대 너비 | 100% | 100% | 1280px (콘텐츠 영역) |
| 상품 그리드 | 2열 | 3열 | 3–4열 |

### 7-3. 핵심 레이아웃 원칙

1. **여백이 디자인이다** — 요소 사이에 충분한 공간이 있어야 고급스럽다
2. **정보 밀도는 낮게** — 한 화면에 너무 많은 정보를 넣지 않는다
3. **시선 흐름은 위→아래 (모바일), Z-패턴 (데스크탑)** — 복잡한 네비게이션 구조 지양
4. **섹션 구분은 여백으로** — 구분선(divider)은 최소화하고, 간격과 배경색 차이로 영역 분리
5. **이미지 비율 통일** — 상품 이미지는 동일한 aspect ratio 유지 (3:4 권장)

## 8. 컴포넌트 설계 원칙

### 8-1. 범용 원칙

| 원칙 | 설명 |
|------|------|
| 한 컴포넌트 = 한 책임 | 하나의 컴포넌트가 너무 많은 역할을 갖지 않음 |
| 상태 완결성 | 모든 인터랙티브 컴포넌트는 default/hover/active/disabled/focus/error 상태 포함 |
| 일관된 모서리 | border-radius 값을 2~3단계로 통일 (예: 4px, 8px, 12px) |
| 그림자는 절제 | 그림자(shadow)는 hover 피드백이나 모달에만 사용. 기본 카드는 그림자 없이 배경색 차이로 구분 |
| 애니메이션 규칙 | 전환은 150–250ms, ease-out 기본. 장식적 애니메이션 금지. 의미 있는 피드백만 |

### 8-2. 주요 컴포넌트 방향

| 컴포넌트 | 방향 |
|----------|------|
| **버튼** | Primary(CTA): 채움+대비. Secondary: 아웃라인 또는 ghost. 크기 3단계(sm/md/lg). 모바일에서 full-width 허용 |
| **카드(상품)** | 이미지 상단 + 정보 하단. 이미지 비율 3:4 고정. hover 시 미묘한 이미지 확대(scale 1.02). 가격은 굵게, 상품명은 보통 |
| **입력(Input)** | 넉넉한 높이(44–48px). 레이블은 항상 표시. placeholder는 보조 텍스트. 포커스 시 border 강조 |
| **모달/바텀시트** | 데스크탑: 중앙 모달. 모바일: 바텀시트. 배경 dim 처리. 닫기 명확 |
| **토스트/알림** | 화면 하단 또는 상단. 짧은 메시지. 자동 닫힘(3–5초). 성공/에러/정보 구분 |
| **탭/필터** | 수평 스크롤 허용(모바일). 선택 상태 명확. 비선택 탭도 터치 영역 충분 |
| **네비게이션** | 상단 GNB 고정. 모바일: 하단 탭 바 또는 햄버거 메뉴. 카테고리 깊이 2단계 이내 |

## 9. 상태 패턴 규칙

> 모든 비동기 데이터를 다루는 화면은 반드시 4가지 상태를 정의해야 한다.

### 9-1. 로딩 상태 (Loading)

| 규칙 | 설명 |
|------|------|
| 전체 페이지 로딩 | 스켈레톤 UI (스피너 금지) |
| 부분 로딩 | 해당 영역만 스켈레톤. 나머지는 정상 렌더링 |
| 버튼 로딩 | 버튼 내부에 spinner + disabled. 텍스트 유지 또는 "처리 중..." |
| 이미지 로딩 | 배경색(placeholder) → blur-up → 원본. LQIP(Low Quality Image Placeholder) 패턴 |
| 로딩 시간 기준 | 200ms 이내 → 로딩 표시 안 함 (깜빡임 방지). 200ms 이후 → 스켈레톤 표시 |

### 9-2. 스켈레톤 UI (Skeleton)

| 규칙 | 설명 |
|------|------|
| 형태 | 실제 콘텐츠의 레이아웃을 반영한 회색 블록 |
| 색상 | 배경보다 약간 진한 회색. 펄스(pulse) 애니메이션 |
| 텍스트 스켈레톤 | 텍스트 위치에 둥근 직사각형. 실제 텍스트 길이의 60~80% |
| 이미지 스켈레톤 | 실제 이미지 비율(3:4)과 동일한 회색 영역 |
| 반복 요소 | 리스트/그리드는 2~4개의 스켈레톤 항목 표시 |
| 절대 금지 | 전체 화면 스피너(spinner). 스피너는 버튼 내부에서만 허용 |

### 9-3. 빈 상태 (Empty State)

| 규칙 | 설명 |
|------|------|
| 구성 | 아이콘(선택) + 메시지 + 행동 유도(CTA) |
| 메시지 톤 | 기계적이지 않게, 따뜻하지만 절제된 어조 |
| 행동 유도 | 반드시 다음 단계를 안내 (예: 장바구니 빈 상태 → "상품 둘러보기" 버튼) |
| 이미지/일러스트 | 대형견 관련 간결한 일러스트 사용 가능. 단, 과하거나 귀엽지 않게 |

**빈 상태 예시 목록:**

| 화면 | 메시지 예시 (en) | CTA |
|------|------------------|-----|
| 장바구니 | "Your cart is empty" | Browse products |
| 위시리스트 | "No saved items yet" | Explore collection |
| 검색 결과 없음 | "No results for '{query}'" | Clear filters / Browse all |
| 주문 내역 없음 | "No orders yet" | Start shopping |
| 리뷰 없음 | "No reviews yet. Be the first!" | Write a review |
| 커뮤니티 피드 | "Nothing here yet" | Create a post |

### 9-4. 에러 상태 (Error State)

| 규칙 | 설명 |
|------|------|
| 인라인 에러 | 필드 직하에 빨간 텍스트. 아이콘 + 메시지 |
| 영역 에러 | 해당 영역에 에러 카드 표시 + 재시도 버튼 |
| 전체 페이지 에러 | 중앙 정렬 에러 메시지 + "다시 시도" + "홈으로" |
| 네트워크 에러 | "연결 상태를 확인해주세요" + 자동 재시도(선택) |
| 토스트 에러 | 일시적 에러(API 실패 등)는 토스트로 알림 |
| 에러 메시지 톤 | 기술 용어 금지. 사용자가 이해할 수 있는 자연어 |
| 에러 코드 | 사용자에게 노출하지 않음. 콘솔/로그에만 기록 |

### 9-5. 상태 패턴 적용 매트릭스

| 화면 | 로딩 | 스켈레톤 | 빈 상태 | 에러 |
|------|------|---------|---------|------|
| 홈 | ○ | 섹션별 스켈레톤 | N/A (항상 콘텐츠 있음) | 섹션별 에러 + 재시도 |
| 상품 목록 | ○ | 상품 카드 그리드 스켈레톤 | 검색 결과 없음 | 목록 에러 + 재시도 |
| 상품 상세 | ○ | 이미지+정보 스켈레톤 | N/A | 전체 에러 + 홈으로 |
| 장바구니 | ○ | 아이템 리스트 스켈레톤 | 빈 장바구니 + CTA | 항목별 에러 |
| 체크아웃 | ○ | 폼 스켈레톤 | N/A | 인라인 에러 + 결제 실패 모달 |
| 마이페이지 | ○ | 주문/위시리스트 스켈레톤 | 각 섹션 빈 상태 | 섹션별 에러 |
| 커뮤니티 | ○ | 피드 스켈레톤 | 빈 피드 + CTA | 피드 에러 + 재시도 |

## 10. 다국어 텍스트 길이 대응 규칙

### 10-1. 언어별 텍스트 길이 특성

| 언어 | 한국어 대비 길이 | 주요 이슈 |
|------|-----------------|-----------|
| **ko** (기준) | 1.0x | — |
| **en** | 1.2–1.5x | 대소문자, 단어 간격 |
| **ja** | 0.8–1.2x | 한자 혼합 시 폭 유사, 히라가나 단독 시 길어짐 |
| **de** | 1.5–2.0x | **합성어로 인해 매우 길어짐**. 가장 주의 필요 |

### 10-2. 대응 규칙

| 규칙 | 설명 |
|------|------|
| **고정 너비 텍스트 금지** | 버튼, 라벨, 탭 등에서 고정 width 사용 금지. min-width + padding 방식 사용 |
| **말줄임(truncation) 기준** | 1줄 말줄임: 상품명, 카테고리명. 2줄 말줄임: 상품 설명 미리보기. 말줄임 시 tooltip 또는 상세 페이지에서 전체 확인 가능 |
| **독일어 기준 테스트** | 모든 UI 텍스트는 **독일어 기준으로 레이아웃 깨짐 테스트** 필수 (가장 긴 언어) |
| **줄바꿈 허용 영역** | 제목, 버튼 라벨은 1줄 유지. 설명 텍스트, 안내 문구는 줄바꿈 허용 |
| **숫자/통화 포맷** | locale 기반 포맷 사용. 예: 49,900원 / $49.90 / ¥5,490 / 49,90 € |
| **날짜 포맷** | locale 기반. 예: 2026.04.13 (ko) / Apr 13, 2026 (en) / 2026年4月13日 (ja) / 13.04.2026 (de) |
| **RTL 미지원** | MVP에서 RTL(아랍어 등) 미지원. 향후 확장 시 CSS logical properties 활용 가능하도록 방향만 고려 |

### 10-3. 컴포넌트별 다국어 대응

| 컴포넌트 | 대응 방식 |
|----------|-----------|
| **버튼** | min-width 사용 + padding 16–24px. 텍스트 길어지면 버튼 너비 자동 확장. 모바일에서 full-width 허용 |
| **탭/필터** | 수평 스크롤. 탭 텍스트 줄바꿈 금지. 독일어 긴 라벨 대비 |
| **네비게이션** | 메뉴 항목은 짧은 키워드 사용. 독일어에서도 1줄 유지 가능한 라벨 선정 |
| **상품 카드** | 상품명 2줄 말줄임. 가격은 항상 표시. 레이아웃 높이 고정, 텍스트 영역 유동 |
| **폼 라벨** | 라벨 위 배치(stacked). 옆 배치(inline) 금지 — 독일어에서 깨짐 |
| **에러 메시지** | 줄바꿈 허용. 최대 2줄 |
| **토스트** | 1줄 권장. 길면 2줄까지 허용. 자동 줄바꿈 |

## 11. 모바일 우선 구조 기준

### 11-1. 원칙

| 원칙 | 설명 |
|------|------|
| **Mobile-first 설계** | 모바일을 기본으로 디자인하고, 데스크탑으로 확장 |
| **모바일이 주 사용 환경** | 커머스 트래픽의 70%+ 가 모바일. 모바일 경험이 매출에 직결 |
| **터치 최적화** | 모든 인터랙션 요소 최소 44×44px. 스와이프 제스처 지원 |
| **한 손 조작 고려** | 주요 CTA를 하단에 배치. 상단 멀리 있는 요소에 대한 의존 줄임 |

### 11-2. 브레이크포인트

| 이름 | 범위 | 용도 |
|------|------|------|
| **mobile** | 0–767px | 기본 설계 기준 |
| **tablet** | 768–1023px | 태블릿 + 작은 랩탑 |
| **desktop** | 1024–1439px | 일반 데스크탑 |
| **wide** | 1440px+ | 와이드 스크린 (max-width 제한) |

### 11-3. 모바일 핵심 UX 규칙

| 항목 | 규칙 |
|------|------|
| **GNB** | 상단 고정. 로고 + 검색 + 장바구니. 높이 56px 이내 |
| **하단 네비게이션** | 홈 / 카테고리 / 커뮤니티 / 마이페이지. 아이콘 + 라벨. 높이 56–64px |
| **상품 그리드** | 2열 기본. 카드 간격 12–16px |
| **상품 상세** | 이미지 스와이프 → 상품 정보 → 사이즈 → 리뷰 → 관련 상품. 하단 고정 CTA(장바구니/구매) |
| **장바구니** | 풀스크린 또는 슬라이드 패널. 하단 고정 결제 버튼 |
| **체크아웃** | 단계별 진행(스텝 표시). 스크롤 최소화. 하단 고정 결제 버튼 |
| **이미지** | 상품 이미지 가로 100% + 스와이프. 핀치 줌 지원 |
| **키보드** | 입력 시 키보드가 CTA를 가리지 않도록 스크롤 조정 |
| **스크롤 복귀** | 리스트 → 상세 → 뒤로 시 스크롤 위치 복원 |

## 12. 이미지 운용 원칙

| 원칙 | 설명 |
|------|------|
| **대형견이 주인공** | 상품 이미지에서 대형견 착용컷이 핵심. 상품만 단독 촬영한 이미지는 보조 |
| **이미지 비율 통일** | 상품 썸네일: 3:4. 배너/히어로: 16:9 또는 4:3. 커뮤니티: 1:1 또는 자유 |
| **배경 일관성** | 상품 사진 배경은 깔끔한 뉴트럴 톤. 라이프스타일 컷은 자연광 환경 |
| **이미지 최적화 필수** | WebP/AVIF 포맷. 반응형 이미지(srcset). LQIP(blur-up) 패턴. lazy loading |
| **이미지 alt 텍스트** | 접근성 + SEO. 상품명 + 견종 + 색상 포함 |
| **과한 이미지 사용 금지** | 이미지는 정보 전달 수단이지 장식이 아님. 의미 없는 이미지 배치 지양 |
