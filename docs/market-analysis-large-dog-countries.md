# 대형견 양육 국가 분석 및 1차 타겟 시장 선정

> 작성: Iseria (planner)
> 최종 수정: 2026-04-13
> 상태: 확정 대기 — 사용자 승인 후 MVP 정책에 반영

---

## 1. 목표

대형견 의류 커머스의 **1차 진출 시장**을 선정하기 위해, 대형견 양육 비율이 높고 반려동물 소비 시장이 활성화된 국가를 분석한다.
단순 반려견 수가 아니라 **대형견 비중 × 소비력 × 온라인 구매 성숙도**를 기준으로 판단한다.

---

## 2. 분석 기준

| 기준               | 설명                                 | 가중치 |
| ------------------ | ------------------------------------ | ------ |
| 대형견 양육 비율   | 전체 반려견 중 대형견(25kg+) 비중    | ★★★★★  |
| 반려동물 시장 규모 | 펫 산업 전체 매출 규모               | ★★★★   |
| 온라인 구매 성숙도 | 이커머스 침투율, 해외직구 경험       | ★★★★   |
| 반려견 의류 문화   | 반려견에게 옷을 입히는 문화적 수용도 | ★★★★★  |
| 물류 접근성        | 국제 배송 인프라, 배송비 부담        | ★★★    |
| 언어/결제 복잡도   | 지원 비용 대비 시장 크기             | ★★★    |

## 3. 주요 국가별 분석

### 3-1. 미국 (United States) 🏆

| 항목        | 분석                                                                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 반려견 수   | 약 9,000만 마리 (세계 1위)                                                                                                                  |
| 대형견 비율 | **매우 높음** — Labrador Retriever(1위), German Shepherd(3위), Golden Retriever(4위), Rottweiler, Great Dane 등 대형견이 인기견종 상위 독점 |
| 시장 규모   | 펫 산업 약 $150B+(2025), 세계 최대                                                                                                          |
| 의류 문화   | 높음 — 기능성 의류(방한·방수·보호), 할로윈·크리스마스 시즌 의류 수요 강함                                                                   |
| 온라인 구매 | 매우 성숙 — Chewy, Amazon, 브랜드 D2C 문화 활성                                                                                             |
| 물류        | 우수 — USPS/UPS/FedEx 인프라, 한국→미국 배송 경험 풍부                                                                                      |
| 특징        | 대형견이 "가족"이라는 인식이 가장 강한 시장. 프리미엄 브랜드 소비 의향 높음. 사이즈 다양성(XL~3XL) 필수                                     |

**종합 점수: 9.5/10** — 1순위 필수 시장

## 7. 국가별 특화 고려사항

### 미국

- 사이즈: XS~3XL 이상 필요, 인치/파운드 단위 병기
- 배송: Free shipping 기준선 중요 (예: $79+)
- 마케팅: Instagram, TikTok, 인플루언서 마케팅
- 법적: California Consumer Privacy Act (CCPA) 대응

### 일본

- 사이즈: cm/kg 단위 (한국과 동일)
- 배송: 배송 추적 필수, 시간대 지정 기대
- UX: 정보량 많은 상세페이지 선호, 상세한 사이즈 가이드
- 결제: 편의점 결제(konbini) MVP 이후 추가 검토
- 법적: 특정상거래법 표기의무

### 독일

- 사이즈: cm/kg (유럽 표준)
- 배송: 환경 의식 높음 → 친환경 포장 언급 권장
- UX: 제품 소재·원산지·안전성 정보 상세 표기 기대
- 결제: Klarna(후불결제) 매우 인기 → MVP에서 Stripe+Klarna 조합 권장
- 법적: GDPR 필수, Impressum(사이트 운영자 정보) 법적 의무, Widerrufsrecht(14일 청약철회)

### 한국

- 사이즈: cm/kg
- 배송: 당일/익일 기대치 높음
- UX: 간결하고 빠른 흐름, 리뷰·후기 의존도 높음
- 결제: 카드/카카오페이/네이버페이/토스
- 법적: 전자상거래법, 7일 청약철회
