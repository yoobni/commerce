> 작성: Iseria (planner)
> 최종 수정: 2026-04-27
> 상태: 1차 확정 — MVP 범위 기준

---

## 1. 목표

대형견(25kg+) 양육자 타겟 글로벌 커머스를 구축한다.
구매(커머스) → 사용 후 공유(커뮤니티) → 운영(어드민)을 **하나의 정책 시스템**으로 묶고,
"대형견에 진짜 맞는 옷을 사기 어렵다"는 실수요 페인을 해소하는 것이 본질 가치다.

KPI 1차 목표 (런칭 후 6개월):

- 가입 → 첫 구매 전환율 12% 이상
- 첫 구매 → 재구매율 25% 이상 (90일 기준)
- 리뷰 작성률 18% 이상 (구매자 기준)
- 글로벌(KR 외) 매출 비중 20% 이상

## 4. 정책

### 4.1 사용자 가치

- **사이즈 신뢰**: 모든 상품은 가슴둘레/등길이 cm 기준 표기 (S/M/L 라벨만 X)
- **대형견 페르소나 우선**: 검색·필터 기본값이 대형견 친화 (체중 25kg+ 토글 즉시 가능)
- **리뷰 = 사이즈 사회적 증거**: 리뷰 작성 시 견종·체중·구매 사이즈 필수 → 다음 구매자에게 노출

### 4.2 비즈니스 가치

- **콘텐츠 → 구매 동선**: 커뮤니티 게시글에서 상품 태깅 → 상품 상세 진입
- **재구매 견인**: 구매 후 30/60/90일 시점 재구매 트리거 (이메일/푸시 — MVP 후)
- **글로벌 노출 우선, 결제는 단계적**: 다국어/통화 표시 먼저, 현지 결제는 시장 검증 후

### 4.3 운영 정책

- 환불은 어드민 승인제 (자동 환불 X)
- 리뷰는 작성 즉시 공개, 신고 누적 시 비공개 전환
- 커뮤니티 신고 3건 누적 시 자동 비공개 → 운영자 검토
- 모든 상태 변경은 AuditLog 기록

### 4.4 기술 정책

- TypeScript strict, `tsc --noEmit` 0에러 후 커밋
- optional 필드는 null 기본값 (undefined 금지)
- 영어 코드 / 다국어 UI
- 이벤트 스키마는 `analytics-kpi-event-schema.md` 단일 출처

## 5. 상태값

### 5.1 회원 (User)

`ACTIVE` → `SUSPENDED` (제재) ↔ `ACTIVE` / `WITHDRAWN` (탈퇴, 30일 후 파기)

### 5.2 주문 (Order)

`PENDING` → `PAID` → `PREPARING` → `SHIPPING` → `DELIVERED` → `CONFIRMED`
취소: `PENDING`/`PAID` → `CANCELED`
환불: `DELIVERED`/`CONFIRMED` → `REFUND_REQUESTED` → `REFUNDED`

### 5.3 배송 (Shipment)

`READY` → `IN_TRANSIT` → `OUT_FOR_DELIVERY` → `DELIVERED`
예외: `RETURNED`, `LOST`

### 5.4 리뷰/게시글

`PUBLISHED` ↔ `HIDDEN` (신고/관리자) → `DELETED`

### 5.5 쿠폰

`ACTIVE` → `EXPIRED` / `EXHAUSTED`
발급: `ISSUED` → `USED` / `EXPIRED`

## 6. 리스크

| 리스크                      | 영향                    | 대응                                                       |
| --------------------------- | ----------------------- | ---------------------------------------------------------- |
| 대형견 사이즈 데이터 부정확 | 반품률 급증 → 손익 악화 | 상품 등록 시 실측 사진 + 견종별 핏 가이드 의무화           |
| 글로벌 배송비 부담          | 해외 전환율 저하        | 국가별 배송비 정책 분리, 일정 금액 이상 무료배송 임계 설계 |
| 단일 PG(Toss) 의존          | KR 외 결제 불가         | 1차는 인지·노출 중심, 2차 단계 Stripe 도입 로드맵 명시     |
| 커뮤니티 어뷰징             | 운영 부담               | 신고 자동 비공개 + 관리자 검토 큐, 제재 이력 누적          |
| Supabase 단일 의존          | 장애 시 전체 정지       | 백업 정책 + 핵심 읽기 경로 캐시                            |
| 환경변수/시크릿 누출        | 보안 사고               | `.env` 커밋 금지, RLS 정책 검토 의무                       |
| 운영 인력 부족              | 어드민 작업 적체        | 알림(미처리 카운트) + 일괄 처리 UI 우선순위 ↑              |
